## 2. STATUS TA'RIFLARI VA MEZONLARI

- `IMPLEMENTED` — Kod to‘liq yozilgan, rasmiy provider API bilan integratsiya qilingan, testlardan o‘tgan va production muhitida ishlashga tayyor.
- `PARTIAL` — Tizimning bir qismi (masalan, faqat Inbound Webhook yoki faqat Dev Mock) to‘liq ishlaydi, biroq to‘liq biznes oqimi (Outbound API, live hisob-kitoblar) yakunlanmagan.
- `MOCK/STUB` — Haqiqiy tashqi chaqiruv amalga oshirilmaydi, lokal ma'lumotlar bilan taqlidiy ishlaydi.
- `NOT IMPLEMENTED` — Ushbu xizmat uchun kod bazasida hech qanday drayver, interfeys yoki kod mavjud emas.
- `CONTRACT_PENDING` — Texnik interfeys loyihalashtirilgan, biroq tashqi provayderning rasmiy shartnomasi, API hujjati yoki ma'lumotlar sxemasi tasdiqlanmagani sababli implementatsiya muzlatilgan.
