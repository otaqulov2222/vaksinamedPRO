# VaksinaMed Desktop (Windows)

Kompyuterda o‘rnatib sinash uchun Electron oynasi. Ichida live ilova ochiladi:
`https://77-83-206-192.sslip.io/`

## Tez ishlatish (dev)

```bat
cd desktop
npm install
npm start
```

## EXE yig‘ish

```bat
cd desktop
npm install
npm run dist
```

Natija:

- `desktop/release/VaksinaMed Setup 1.0.0.exe` — o‘rnatkich
- `desktop/release/VaksinaMed-Portable-1.0.0.exe` — o‘rnatmasdan ishga tushadi

## Izoh

Bu native mobil ilova emas — telefon UI’sining Windows dasturi. Push va ba’zi brauzer imkoniyatlari Electron qoidalariga bog‘liq.
